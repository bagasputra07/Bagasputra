🎯 Pengantar Generic

Apa itu Generic? Fitur untuk membuat kode yang bekerja dengan berbagai tipe data.

Analog: Kotak penyimpanan yang bisa menampung apa saja, tapi dengan label tipe.

✅ Type Safety ✅ Code Reusability ✅ Compile-time Checking

⚠️ Masalah Tanpa Generic

// ❌ Kode Bermasalah (Tanpa Generic)
class Box {
    dynamic data; // Bisa apa saja - TIDAK AMAN!
    Box(this.data);
}

void main() {
    var box = Box("INI CONTOH SALAH");
    int value = box.data; // Runtime error jika bukan int!
    print(value);
}
// ⚠️ Bahaya: Tidak ada jaminan tipe data, bisa menyebabkan runtime error.

✅ Contoh Benar dengan Generic

// Nama: Muhammad Bagas Putra Andeza
// NIM: 251410003
// KELAS: SI2A
class Box<T> {
    T data;
    Box(this.data);
}

void main() {
    var intBox = Box<int>(42);
    var stringBox = Box<String>('Hello');
    int value = intBox.data; // ✅ Aman, pasti int
    print(value); // Output: 42
}

📝 Sintaks Generic Dasar

Type parameter: <T>, <E>, <K, V>

Konvensi: T = Type, E = Element (collection), K, V = Key, Value, R = Return type

class MyClass<T> {
    T data;
    MyClass(this.data);
    T getData() => data;
}

T myFunc<T>(T value) => value;

🔒 Generic dengan Extends (Constraints)

📌 Keyword extends → membatasi tipe data yang dapat digunakan.

class NumberBox<T extends num> {
    T value;
    NumberBox(this.value);
    T getValue() => value;
}

void main() {
    var intBox = NumberBox<int>(10); // ✅ Valid
    var doubleBox = NumberBox<double>(3.14); // ✅ Valid
    // var stringBox = NumberBox<String>("test"); ❌ ERROR
}

🗄️ Studi Kasus: Class Cache<T>

class Cache<T> {
    final Map<String, T> _storage = {};
    void set(String key, T value) => _storage[key] = value;
    T? get(String key) => _storage[key];
}

💻 Soal 1: Class Repository<T>

class Repository<T> {
    final Map<int, T> _data = {};
    int _nextId = 1;
    void save(T item) { _data[_nextId++] = item; print('Saved: $item'); }
    T? getById(int id) => _data[id];
    List<T> getAll() => _data.values.toList();
}

💻 Soal 2: Fungsi swap<T>

void swap<T>(List<T> list, int i, int j) {
    if (i == j) return;
    T temp = list[i];
    list[i] = list[j];
    list[j] = temp;
}

💻 Soal 3: Class Triple<A, B, C>

class Triple<A, B, C> {
    A first; B second; C third;
    Triple(this.first, this.second, this.third);
    void printTriple() => print('($first, $second, $third)');
}

📖 Ringkasan

🎯 Poin Penting:

  • Generic membuat kode type-safe dan reusable
  • Bisa digunakan di class, fungsi, collections
  • Type inference memudahkan penggunaan
  • Constraints (extends) membatasi tipe yang diperbolehkan

📌 Best Practice:

  • Gunakan generic untuk menghindari dynamic
  • Gunakan extends untuk membatasi tipe
  • Manfaatkan type inference untuk kode lebih bersih
