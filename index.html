PENGERTIAN OOP




Object Oriented Programming (OOP) tidak hanya sekadar teknik pemrograman, 
tetapi merupakan pendekatan desain sistem yang meniru cara manusia memahami dunia nyata. 
Dalam kehidupan sehari-hari, kita mengenali entitas sebagai objek yang memiliki 
karakteristik dan perilaku. OOP mengadopsi konsep ini ke dalam pengembangan 
perangkat lunak sehingga struktur program menjadi lebih intuitif dan mudah dipahami.





OOP bertujuan untuk meningkatkan modularitas sistem, yaitu dengan memecah 
program besar menjadi bagian-bagian kecil yang terorganisir dalam bentuk class. 
Setiap class bertanggung jawab atas satu konsep atau entitas tertentu, 
sehingga pengembangan dan pemeliharaan sistem menjadi lebih terstruktur.





Selain itu, OOP mendukung prinsip reusability atau penggunaan ulang kode. 
Class yang telah dibuat dapat digunakan kembali dalam proyek lain tanpa perlu 
menulis ulang logika yang sama. Hal ini sangat penting dalam pengembangan 
perangkat lunak modern yang menuntut efisiensi waktu dan konsistensi kualitas.





Dalam praktiknya, OOP memiliki empat pilar utama, yaitu 
Encapsulation, Abstraction, Inheritance, dan Polymorphism. 
Keempat prinsip ini memungkinkan sistem menjadi lebih fleksibel, aman, dan 
mudah dikembangkan. Meskipun pada laporan ini lebih difokuskan pada 
Encapsulation dan Constructor, Dart sebagai bahasa pemrograman 
mendukung seluruh pilar tersebut secara native.





Dengan menerapkan paradigma OOP, pengembang dapat membangun sistem yang 
scalable (mudah dikembangkan), maintainable (mudah dirawat), 
dan robust (tahan terhadap kesalahan). Pendekatan ini menjadi fondasi 
utama dalam pengembangan aplikasi modern, termasuk framework Flutter 
yang menggunakan Dart sebagai bahasa utamanya.





  




1. CLASS DAN OBJECT



Pada source code ini, class Car memiliki dua atribut yaitu model dan color.
Method start() dan stop() menggambarkan perilaku objek mobil.
Class ini menunjukkan konsep dasar OOP yaitu pembuatan objek dari sebuah blueprint (class).


  

  

// Nama   : Muhammad Bagas putra andeza

class Car {
  String model; // Properti model
  String color; // Properti warna

  // Constructor untuk inisialisasi model dan color secara langsung
  Car(this.model, this.color);

  // Method untuk menyalakan mobil
  void start() {
    print('Engine Online: $model'); // Menampilkan pesan dengan nama model

  Car myCar = Car("Ferrari", "Hitam");

  myCar.start();

  // Menampilkan atribut warna
  print(myCar.color);

4. ENCAPSULATION



Atribut name diawali dengan underscore () yang menandakan 
bahwa variabel tersebut bersifat private.
Akses dilakukan melalui method setName() dan getName().
Konsep ini disebut Encapsulation, yaitu membatasi akses langsung ke data.


  

  // Nama   : Muhammad Bagas putra andeza 
// Nim    : 251410003
// Kelas  : Si2A
class Person {
  String _name; // Atribut private (diawali underscore)
  int age;      // Atribut publik

  // Constructor
  Person(this._name, this.age);

  // Setter untuk mengubah nilai _name secara aman
  void setName(String name) => _name = name;

  // Getter untuk mengambil nilai _name
  String getName() => _name;
}

void main() {
  // Membuat objek dari class Person
  Person person = Person("Muhammad bagas putra andeza", 18);

  print(person.age);        // Menampilkan umur
  person.setName("BAGAS");  // Mengubah nama
  print(person.getName());  // Menampilkan nama hasil getter
}
